## 1. サービス概要（※最後に書いてOK）
  - ドローン運営管理ツール

## 2. このアイデアはどこから生まれたか 
  - 2025年に無償アプリを使用してドローン飛行日誌及び整備報告書を作成していた。 アプリのバージョンアップに伴い、データがまっさらになって困った。
  - 飛行練習中に見回り中の警官に日誌を提示求められたときの法規違反の可能性に恐怖した。  
---

## 3. 課題の整理
  -  現場で数タップするだけで、国交省（DIPS）への報告に必要な項目を漏れなく記録。Excelへの転 
     記ストレスや、報告漏れの不安を解消します。
  -  機体、バッテリー、飛行時間をそれぞれバラバラにExcelで管理するのが限界。
     自動で一元管理できる。
  -  個人が嫌々義務で記録するのではなく、進んでアプリを使いたくなるような心理的な
     負担の軽減。

## 4. 想定ユーザーについて
### 4-1. 想定しているユーザー
 - 40代～50代のあまり情報管理が得意ではない「趣味の個人ユーザー」

### 4-2. 実際に使われる可能性について(需要・存在確認)
 - 機体を片付けや帰りの車に乗り込んだ直後のタイミング。
 - 疲れて手早く記録を終わらせたいと思っている場面。

## 4-3. 「なぜ・どのように使い続けてもらえるのか」
 - アバター育成時のほっこり感を得るため使ってみようかなと感じてもらう。

## 6. このサービスで提供したい価値
  -  必要な項目の記入漏れや報告もれの不安解消。
  -  サーバ一元管理によるローカルデータ喪失リスクや自己管理の開放。 
  -  多くの記入項目の手間
  -  アバター育成によるアプリ継続医師の付与

## 7. このアプリで実現すること
### MVPで作る機能

- (1)ユーザ登録・ログイン
- (2)1操作者の飛行者の飛行記録の登録
- (3)記録一覧の表示・検索
- (4)1機体分の整備記録
### 本リリースで作る機能
- (1)位置情報をMAP取り込み
- (2)複数機体登録
- (3)複数操作者の管理記録の登録
- (4)機体のドローン保険登録とアラート機能
- (5)オフラインでの対応機能
