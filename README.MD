## 1. サービス概要（※最後に書いてOK）
- このサービスはどんなサービスか（3行以内）

  ドローン運営管理ツール

- 誰の、どんな課題を、どう解決するか

  個人ユーザの国交省(DIPS)情報の転記入力ミスや記入漏れ不安の解消

  記入項目内容がそらぞれバラバラに管理され、一元管理されない。

  個人がアプリを使わなくなってしまい、ドローンの運行日誌の管理が雑になってしまう。

## 2. このアイデアはどこから生まれたか 
### 2-1. きっかけとなった体験・感情
このアイデアの元になった
**自分自身の体験・感情・違和感**を教えてください。

  - 2025年に無償アプリを使用してドローン飛行日誌及び整備報告書を作成していた。 アプリのバージョンアップに伴い、データがまっさらになって困った。
  - 飛行練習中に見回り中の警官に日誌を提示求められたときの法規違反の可能性に恐怖した。

## 3. 課題の整理
### 3-1. 表に見えている困りごと
  -  現場で数タップするだけで、国交省（DIPS）への報告に必要な項目を漏れなく記録。Excelへの転 
     記ストレスや、報告漏れの不安を解消します。
  -  機体、バッテリー、飛行時間をそれぞれバラバラにExcelで管理するのが限界。
     自動で一元管理できる。

### 3-2. 本当に解決したい課題は何か
  -  個人が嫌々義務で記録するのではなく、進んでアプリを使いたくなるような心理的な
     負担の軽減。

## 6. このサービスで提供したい価値
### 6-1. ユーザーの変化
 今まで紙やEXCELなどで管理していたが、操作簡単で直感的につかるし、無料でつかえるならこちらに切り替えてもいいかな。

### 6-2. 価値を一文で表す

  -  必要な項目の記入漏れや報告もれの不安解消。
  -  サーバ一元管理によるローカルデータ喪失リスクや自己管理の開放。 
  -  多くの記入項目の手間
  -  アバター育成によるアプリ継続医師の付与

## 7. このアプリで実現すること
### MVPで作る機能

- (1)ユーザ登録・ログイン
- (2)1操作者の飛行者の飛行記録の登録
- (3)記録一覧の表示・検索
- (4)1機体分の整備記録
- (5)アバター成長画像表示
### 本リリースで作る機能
- (1)位置情報をMAP取り込み
- (2)複数機体登録
- (3)複数操作者の管理記録の登録
- (4)機体のドローン保険登録とアラート機能
